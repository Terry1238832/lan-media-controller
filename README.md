# 四端局域网媒体控制器 (LanMediaController v2.1)

全平台**真正原生实现**（Windows / macOS / Android / iOS），**免匹配码、启动即自动开房**，实时发现同一网络下其他设备房间，一键加入即可跨端控制媒体播放（支持 QQ音乐、网易云音乐、Spotify、Apple Music、浏览器、本地播放器等）。

## 核心特性

- **启动自动开房，无需匹配码**：打开软件默认立即开启名为「`<设备名>的房间`」的房间，修改设备名后房间名自动同步更新；局域网/同网络下其他设备自动出现在「可加入的其他设备房间」列表中，点击「加入」即可直连控制，随时可点「回到我的房间」。
- **真实局域网 / Wi-Fi 名称显示**：通过各平台原生网络 API 获取当前 Wi-Fi 名称或真实局域网 IP。
- **极简 4 项媒体控制**：每个播放器仅保留 4 项核心控制：
  1. **拖动进度条并开始播放**
  2. **上一章 / 上一曲 (`⏮`)**
  3. **播放 / 暂停 (`▶ / ⏸`)**
  4. **下一章 / 下一曲 (`⏭`)**
- **局域网直连 + 同网络自动发现兜底**：优先通过局域网 UDP (`41234`) + HTTP (`41235`) 毫秒级直连；若 Windows 防火墙或路由器 AP 隔离拦截，自动通过同路由器私有哈希通道无缝发现与同步。
